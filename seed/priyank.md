## 4. AIRO — Attendance Intelligence & Recognition Operations

Developed a **full-stack facial-recognition attendance system** using Python, Flask, OpenCV, Scikit-learn, Supabase, JavaScript, and Plotly to automate employee identification and attendance marking.

### Key Contributions

* Implemented a computer-vision pipeline using **Haar Cascade** for face detection and distance-weighted **KNN classification with up to 5 neighbors**, operating on normalized 50×50 face representations.
* Built browser-based real-time camera recognition using JavaScript `getUserMedia()`, removing dependency on server-side webcams and enabling cloud deployment.
* Integrated **Supabase PostgreSQL, Storage, and Authentication** for employee profiles, biometric face samples, attendance records, and secure administrator access with private biometric storage.
* Implemented automated daily attendance processing, database-level duplicate prevention, interactive Plotly analytics, storage-utilization tracking, and CSV export capabilities.
* Designed a responsive AI command-center interface with glassmorphism styling, live camera and recognition status indicators, and analytical dashboards.
* Structured the application architecture to support future migration from traditional KNN-based recognition to CNN and deep face-embedding models.

### Recognition Pipeline

Haar Cascade Face Detection
        ↓
50×50 Normalized Face Representations
        ↓
Distance-Weighted KNN Classification
        ↓
Real-Time Browser Camera Recognition
        ↓
Automated Attendance
